
# 💰 MFX Currency Converter - 

A lightweight, web-based currency converter built with **Python** and **Streamlit**, designed to make currency conversion simple and accessible.

## 🌐 Live Demo - 

**Try it here:** [MFX Currency Converter](https://mfx-currency-converter.streamlit.app/)

## 📌 About the Project - 

MFX Currency Converter is a web application that allows users to convert an amount from one currency to another through a simple, user-friendly interface. Built with Python and Streamlit, the project demonstrates the practical application of Python programming in developing interactive web applications.

## ✨ Features - 

- 💱 **Currency Conversion** — Convert amounts between supported currencies.
- 🌍 **Multiple Currencies** — Select from the currencies available in the application.
- ⚡ **Quick Results** — View conversion results through a streamlined workflow.
- 🖥️ **Simple Interface** — Use an intuitive interface without unnecessary complexity.
- 🌐 **Web-Based Access** — Access the application directly through a browser.

## 🛠️ Tech Stack

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Python installed on your system.
- Git installed on your system.

### 1. Clone the Repository

```bash
git clone https://github.com/JD-Jaidev/Currency-Converter.git
```

### 2. Navigate to the Project Directory

```bash
cd Currency-Converter
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Launch the Application

```bash
streamlit run app.py
```

Once the application starts, open the local URL displayed in your terminal.

## 🚀 How to Use - 

1. Open the [MFX Currency Converter](https://mfx-currency-converter.streamlit.app/) web application.
2. Enter the amount you want to convert.
3. Choose the source and target currencies from the available options.
4. View the converted amount.
