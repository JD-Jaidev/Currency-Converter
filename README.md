💱 MFX Currency Converter

📌 About the Project

MFX Currency Converter is a simple web application built using Python and Streamlit. It helps users convert amounts from one currency to another through an easy-to-use interface.

🌐 Live Demo

Try the application here:

"MFX Currency Converter" (https://mfx-currency-converter.streamlit.app/)

✨ Features

- 💱 Easy currency conversion
- 🌍 Support for different currencies
- 🖥️ Simple and user-friendly interface
- ⚡ Quick conversion results
- 🌐 Accessible through a web browser

🛠️ Tech Stack

- Python – Handles application logic.
- Streamlit – Creates the web interface.

⚙️ Installation

1. Clone the Repository

git clone https://github.com/JD-Jaidev/Currency-Converter.git

2. Open the Project Folder

cd MFX-Currency-Converter

3. Install the Required Packages

pip install -r requirements.txt

4. Run the Application

streamlit run app.py

🚀 How It Works

1. Open the MFX Currency Converter website.
2. Enter the amount you want to convert.
3. Select the currencies.
4. View the converted amount.
